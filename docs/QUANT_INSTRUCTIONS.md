# Message for Quant

Copy everything in the box below and send it to Quant in the Claude project it runs in.
Change the folder name in the first line if yours is called something else.

---

```
From now on the CRM (crm.cltd.co.uk) reads the Google Drive folder you save email
attachments into, every 5 minutes, and files each file into the right job, subcontractor
or quote. To make that work well, please follow these rules when you save attachments:

1. Keep saving every attachment into the same Drive folder you use now (the one shared
   with crm-inbox@…iam.gserviceaccount.com). Sub-folders inside it are fine.

2. Put each email's attachments in their own sub-folder named:
      YYYY-MM-DD – Sender Company (sender@email) – Email subject
   e.g. "2026-11-15 – ABC Groundworks (tom@abcground.co.uk) – RE Arcady groundworks quote"
   Keep it under 150 characters and remove / \ : * ? " < > | from the name.
   The CRM uses this name to tell which job and which subcontractor a file belongs to.

3. Keep each file's original name. Don't rename files to generic names.

4. Keep removing duplicates like you do now: if the same email went to several of us,
   save its attachments once.

5. Unzip .zip attachments into that email's sub-folder (the CRM can't read inside zips).
   For WeTransfer / Dropbox / OneDrive / Google Drive links in the email, download the
   actual files into the same sub-folder when you can.

6. Don't save email-signature images, logos or calendar invites (image001.png,
   logo.jpg, .ics files). The CRM ignores them anyway, so this just keeps the folder tidy.

7. Never move, rename or delete files after saving them, and never move them out of
   the folder. The CRM reads them from there.

8. Don't upload anything into the CRM yourself. The CRM collects from the folder, so
   uploading directly would file things twice.

9. Keep everything else you do with the folder (collecting data, summaries, the Xero/CRM/
   design portal info) exactly as now. The CRM only reads the folder and changes
   nothing in it.
```

---

## What to expect
- New attachments show up in **CRM › Inbox** within about 5 minutes of Quant saving them.
- Anything unclear waits in **Inbox › To check**. Fixing it there doesn't change anything
  in Drive.
